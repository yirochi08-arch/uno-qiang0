# UNO 抢0

经典 UNO 加「抢0」：谁出了 0，全桌抢着拍，最慢的罚摸牌。可以和电脑玩，也可以开房间和朋友联机，空位由电脑补上。打开网页就能玩，不用注册登录。

- 游戏页：`index.html`（由 `build.py` 生成，单文件，字体和联机库都内嵌在里面）
- 源码：`src/page.html`
- 联机：经 EMQX 的免费公共 MQTT 服务器转发（国内线路优先，连不上换海外线路）。整局牌在房主的页面上运行，房主请一直开着页面。
- 「特殊玩法」三选一（设置/房间里选，默认经典）：
  - 加牌可叠加：+2 能接任意颜色的 +2 或 +4，叠进 +4 后只能接 +4，接不上的人摸走全部累计并停一轮；叠加时出 +4 不受「手里没有当前颜色」限制。成文参考：UNO Show 'Em No Mercy 的叠加规则（只能叠同值或更大的加牌，不要求同色）。
  - +4 可质疑：按 Mattel 官方说明书（instruction sheet 42001）。+4 随时能出，出牌前手里没有当前颜色才算合规；只有被 +4 的下家能质疑，出牌人把手牌亮给他；违规则出牌人摸 4 张，合规则质疑人摸 6 张。说明书没写的两点按此处理：质疑成功后质疑人不用摸、接着正常出牌；颜色照出牌人指定的算。
- 进房间后在圆桌上点空位选座，出牌按座位顺时针轮；没选座的人开局时自动补空位，剩下的由电脑坐。
- Claude 版：`claude/artifact.html`，直接发布成 claude.ai artifact，联机走 artifact 自带的 room 能力（只有登录 claude.ai 的人能进房间）。游戏逻辑和网页版一致，改功能时两边都要改。

改完 `src/page.html` 后运行：

```bash
python build.py
```

第三方：MQTT.js（MIT，`vendor/mqtt.LICENSE.md`），Rubik 字体（SIL OFL 1.1，`fonts/OFL.txt`）。
