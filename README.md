# 一起玩牌

打开就能玩的牌桌，不用注册登录。可以和电脑玩，也可以开房间叫朋友，空位由电脑补上。

| 页面 | 玩法 | 源码 |
|---|---|---|
| `index.html` | 玩法大厅（旧的 UNO 邀请链接 `/#房间号` 会自动跳到 UNO） | `src/hub.html` |
| `uno.html` | UNO 抢0（2–10 人） | `src/page.html` |
| `poker.html?g=ddz` | 斗地主（3 人） | `src/poker.html` |
| `poker.html?g=pdk` | 跑得快（3 人，16 张） | `src/poker.html` |

改完 `src/` 里的文件后运行：

```bash
python build.py
```

每个页面都打包成一个文件：字体、MQTT.js 和联机代码（`src/netroom.js`）都内嵌在里面，不依赖 Google 或 CDN。

## 联机

经 EMQX 的免费公共 MQTT 服务器转发（国内线路优先，连不上换海外线路）。整局牌在房主的页面上运行，房主请一直开着页面。进房间后在圆桌上点空位选座；有人掉线电脑先代打，回来接着出；太久不动电脑代出一手。

## UNO 抢0

经典 UNO + 抢0（谁出了 0 全桌抢拍，最慢的罚摸）。「特殊玩法」三选一：

- 加牌可叠加：+2 能接任意颜色的 +2 或 +4，叠进 +4 后只能接 +4，接不上的人摸走全部累计并停一轮；叠加时出 +4 不受「手里没有当前颜色」限制。成文参考：UNO Show 'Em No Mercy 的叠加规则（只能叠同值或更大的加牌，不要求同色）。
- +4 可质疑：按 Mattel 官方说明书（instruction sheet 42001）。只有被 +4 的下家能质疑；违规则出牌人摸 4 张，合规则质疑人摸 6 张。说明书没写的两点按此处理：质疑成功后质疑人接着正常出牌；颜色照出牌人指定的算。

## 斗地主

按国家体育总局三人斗地主规则（维基百科「斗地主」条目）：叫分 1/2/3（只能往高叫，都不叫重发）；顺子 5 张起、连对 3 对起、飞机带同数量单牌或对子、四带两单或两对；炸弹、王炸、春天、反春各翻倍；地主一人对两家，输赢双份。没做「加倍」环节。

## 跑得快

经典 16 张（4399、边锋等平台玩法说明，各地细节不同）：去掉大小王、♥♣♦2 和 ♠A 共 48 张；第一局 ♠3 先出且必须带 ♠3，之后上局赢家先出；连对 2 对起，三带二带任意两张，三张/三带一只能最后一手；有大必压；下家报单时出单张必须出最大的；剩几张赔几分，剩 1 张不赔，一张没出（被关）翻倍；炸弹现结，另外两家各付 10 分。
